2) What HookFlow is

HookFlow helps you plan and export short-form marketing-style video content using templates, previews, and on-device workflows. Optional features can use a backend server you configure and, when enabled on that server, AI providers (such as OpenAI-compatible APIs or Google Gemini) or public data sources for insights-style features.

3) Requirements

  • iPhone / iPad running a supported iOS/iPadOS version listed on the App Store.
  • Network: optional cloud features require internet access to reach your configured backend and third-party services.
  • Photos (optional): used only when you choose to pick media or save exports; grant access in Settings → HookFlow if prompts were declined earlier.

4) Backend URL & connectivity

In the App, open Settings → Backend & AI (or equivalent environment screen) and set:

  • Simulator / same Mac: often http://127.0.0.1:8787 or your machine’s LAN IP with port 8787, if your server listens there.
  • Physical iPhone on the same Wi‑Fi: use your computer’s LAN IP address (not localhost), e.g. http://192.168.x.x:8787. Ensure the phone can reach that host (firewall/VPN/proxy).
  • Production: use an HTTPS URL with a valid certificate where possible.

If requests fail: confirm the server is running, the port matches, and iOS can reach the host (try Safari on the device to open the server’s health/status URL if exposed). Avoid pasting secrets into email; rotate tokens if exposed.

5) AI & cloud generation

Script generation and similar cloud jobs depend on your backend and how it is configured (API keys, models, quotas). The App shows job status and messages when available.

  • If you see errors about AI not being configured, the server must have valid provider credentials and a healthy /status (or equivalent) response.
  • Rate limits (HTTP 429) or outages (503) may require waiting or retrying; check provider dashboards.
  • In-app consent: optional personalization may be required for certain cloud/AI flows—review choices on the privacy/consent screens and Settings.

6) Public insights & optional sources

Features that rely on “public insights” send configuration to your backend when enabled. If a source is disabled or not configured on the server (for example missing credentials for a third-party API), results may be empty or jobs may fail—check backend logs and toggles.

7) Jobs: errors and messages

Open the Jobs screen to view status, phase, and error text. Messages often originate from the network or upstream API. Typical steps:

  • Verify network and backend reachability.
  • Confirm authentication token (if required) is still valid.
  • Retry after a few minutes if the service was rate-limited or temporarily unavailable.

8) Export & performance

Video export can be CPU-intensive. If export is slow or fails: close other heavy apps, free storage, lower device load, and retry. On iPad, allow the process to finish before leaving the App. If you use dialogue text on export, very long scripts may affect layout or duration—adjust content and try again.

9) Privacy, language, and reset

  • Language can be changed in Settings; the App stores your preference on-device.
  • Optional on-device analytics and personalization can be reviewed under Settings → Privacy & data. Use Reset privacy & data choices there if you want to clear saved consent and choose again on next launch.
  • For a full local reset of some data, you may uninstall the App (subject to iOS behavior) or use in-app controls where provided.

10) Response times

We aim to respond to support email as soon as practical. Automated receipt is not guaranteed; if you do not hear back within several business days, verify the address and retry with the details in section 1.
